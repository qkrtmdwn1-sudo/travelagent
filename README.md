# 여행 일정 설계 에이전트 MVP

한국어로 여행 정보를 입력하면 하루별 일정표, 지도/검색 링크, 예약 체크리스트, 앱 안 알림, 읽기 전용 공유 링크를 만들어주는 Next.js MVP입니다.

## 실행

Windows에서 더블클릭으로 실행하려면 `start-travel-agent.cmd`를 실행하세요. 처음 실행할 때는 패키지를 설치하고, 이후에는 앱 서버를 켠 뒤 브라우저를 엽니다.

```bash
npm install
npm run dev
```

OpenAI Responses API를 사용하려면 `.env.example`을 `.env.local`로 복사하고 `OPENAI_API_KEY`를 입력하세요. 키가 없으면 앱은 내장 샘플 에이전트로 동작합니다.

Google 지도 기반 실시간 장소 추천을 쓰려면 Google Cloud에서 Places API (New)를 활성화하고 `GOOGLE_PLACES_API_KEY`를 추가하세요. 키가 있으면 평점과 후기 수를 참고해 관광지, 맛집, 우천 대안 후보를 우선 배치합니다.

## 포함 기능

- 대화형 여행 일정 생성
- “덜 걷게”, “맛집 위주”, “비 오는 날 대안” 같은 수정 요청 반영
- 하루별 시간표, 이동, 예상 비용, 예약 필요 여부 표시
- 웹 검색, 지도, 날씨 확인 링크 제공
- 읽기 전용 공유 링크
- Markdown 문서, 캘린더 파일, PDF 인쇄 내보내기
- 앱 안 알림과 API 확장 제안 질문

## MVP 범위

- 실제 예약, 결제, 공동 편집, 투표, 이메일/메신저 알림은 포함하지 않습니다.
- 브라우저 저장소를 우선 사용합니다. 운영 배포에서는 사용자 계정과 서버 DB를 붙이면 됩니다.
- 항공/숙소/지도 API는 추후 확장 지점으로 남겨두었습니다.
